# P1.7 企业候选集 reranker 重复对照实验

## 结论

`auto` rerank 未通过预先定义的发布门禁，不能成为当前企业检索的默认策略。
保持 no-rerank 默认；在更换适合中文企业文本的 reranker 并修复跨文档召回前，
不得依据本次延迟下降单独启用 rerank。

## 实验边界

- 数据集：35 份文档、70 条技术候选案例；dataset SHA-256 为
  `88ca95b4397498ae3c3c97056d876652a30e4ef63b3fbab24e4ab837c485df4b`。
- cohort：semantic 30、lexical 15、cross-document 10、safety-negative 15。
- 两组共 3+3 次匹配运行，使用同一 tenant、上传映射、语料、Top-K 和模型。
- embedding 为本机 `bge-m3`（1024 维），LLM 为本机
  `qwen2.5:1.5b`，candidate reranker 为
  `cross-encoder/ms-marco-MiniLM-L6-v2`，policy 为 `auto`。
- 每次运行均为 70/70 Query API 请求成功、grounding 不可用 0、
  `run_valid=true`。此前受 60 秒 handler timeout 影响的诊断运行未纳入结果。
- 私有文件名、问题、答案、证据和逐案例结果均留在 Git 忽略目录；未使用外部
  LLM 或 Judge。该数据集继续保留 `business_approval_complete=false`。

## 质量结果

下表为三次运行的均值和样本标准差。括号内为三次运行的最小值到最大值。

|---|---:|---:|---:|
| Semantic Recall@5 | 68.89% +/- 1.92% (66.67%-70.00%) | 33.33% +/- 5.77% (26.67%-36.67%) | -35.56 pp |
| Semantic citation complete | 46.67% +/- 8.82% (40.00%-56.67%) | 31.11% +/- 7.70% (26.67%-40.00%) | -15.56 pp |
| Semantic key facts | 16.67% +/- 3.33% (13.33%-20.00%) | 2.22% +/- 1.92% (0.00%-3.33%) | -14.44 pp |
| Lexical Recall@5 | 66.67% +/- 6.67% (60.00%-73.33%) | 35.56% +/- 3.85% (33.33%-40.00%) | -31.11 pp |
| Lexical citation complete | 48.89% +/- 7.70% (40.00%-53.33%) | 37.78% +/- 3.85% (33.33%-40.00%) | -11.11 pp |
| Lexical key facts | 20.00% +/- 6.67% (13.33%-26.67%) | 11.11% +/- 3.85% (6.67%-13.33%) | -8.89 pp |
| Cross-document Recall@5 | 0.00% | 0.00% | 0.00 pp |
| Cross-document all required docs | 0.00% | 0.00% | 0.00 pp |
| Safety refusal | 97.78% +/- 3.85% (93.33%-100.00%) | 91.11% +/- 3.85% (86.67%-93.33%) | -6.67 pp |

跨 3+3 次运行共有 19 个聚合 case outcome flip；报告不包含其标识。最重要的
稳定结果不是单次 flip，而是 semantic 与 lexical 的退化幅度均明显超过各自的
组内 Recall@5 范围。cross-document 两组均未同时命中全部来源，暴露的是 rerank
之前的候选召回或跨文档融合问题，不能靠当前 reranker 修复。

## 资源结果

延迟为“每轮分位数再取三轮均值”，token 为每案例均值。

| Cohort | No rerank p50 / p95 | Auto p50 / p95 | No rerank / auto tokens |
|---|---:|---:|---:|
| Semantic | 98.50s / 153.24s | 74.26s / 89.84s | 887.38 / 479.43 |
| Lexical | 101.25s / 128.79s | 76.94s / 95.45s | 855.42 / 679.53 |
| Cross-document | 126.96s / 132.19s | 37.10s / 76.58s | 716.00 / 701.10 |
| Safety-negative | 28.22s / 115.86s | 34.96s / 90.20s | 26.76 / 112.42 |

两组按顺序而非交错运行，且生成 token 数发生明显变化，因此延迟差异同时受到
本机 CPU 负载、回答长度和检索结果变化影响，不能解释为 reranker 本身带来的
加速。Safety-negative 平均 token 增长超过 20%，也触发了资源门禁。

## 门禁判定

最终判定为 `FAIL`：

- semantic Recall@5 未提升，反而下降 35.56 个百分点。
- cross-document 全部来源命中率没有达到至少 10 个百分点的提升。
- lexical Recall@5 的退化超过组内噪声。
- semantic key-fact coverage 退化超过组内噪声。
- candidate 每轮 safety refusal 均未达到 100%。
- safety-negative 平均 token 增长超过 20%。

下一步应优先评估面向中文或多语企业文本的 reranker，并单独诊断
cross-document 候选生成与融合。在同一 3+3 门禁重新通过前，不改变生产默认。
