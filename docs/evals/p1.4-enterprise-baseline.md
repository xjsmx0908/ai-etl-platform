# P1.4 企业中文银标基线

## 范围与数据边界

本轮在 2026-08-20 使用 `rag_datas/` 中全部 40 份真实文档完成本地评测，
其中 13 份按 `confidential` 处理。数据集包含 114 条自动银标：109 条可回答
样本和 5 条无答案样本。正文、文件名、问题、答案、证据和逐条报告均位于
Git 忽略目录；生成和评测未向外部 LLM 或 Judge 传输数据。

银标由本地 `qwen3:1.7b` 草拟，并通过逐字证据、PII、关键短语和结构校验。
它适合发现系统短板，但尚未经过业务所有者确认，不能作为上线验收金标。
多数自动问题与源证据存在较高词面重叠，因此本轮检索结果可能高于真实员工
自然提问表现；后续 gold 集必须加入人工改写、同义表达和跨文档问题。

## 基线配置

- Embedding：本地 `bge-m3`，1024 维。
- 生成模型：本地 `qwen2.5:1.5b`，上下文上限 1,200 字符，输出上限 64 tokens。
- 检索：Hybrid Top5，不启用 reranker。
- 运行：每条 query 单次测量，连续命中要求为 1，等待窗口为 1 秒。
- Grounding verifier 和 LLM-as-a-Judge 均关闭。

## 聚合结果

| 指标 | 结果 |
|---|---:|
| Recall@1 / @3 / @5 | 66.97% / 80.73% / 83.49% |
| 正样本 Top5 命中 | 91 / 109（83.49%） |
| 检索断言通过 | 96 / 114（84.21%） |
| 答案断言通过 | 30 / 114（26.32%） |
| 端到端通过 | 28 / 114（24.56%） |
| 无答案样本通过 | 5 / 5（100%） |
| 总 token | 120,803 |

失败归因互斥聚合为：18 条检索未命中、27 条命中后缺少可验证引用、41 条
命中后未覆盖银标关键事实。其余 28 条端到端通过。机密权限正样本检索通过
27/33，端到端通过 5/33；这证明当前权限链路能够参与评测，但机密文档的回答
质量仍需重点改善。

## 结论与后续门禁

本轮证明真实 Office/PDF 文档可以完成解析、入库、权限查询和本地评测，且无
答案样本全部正确拒答。主要瓶颈已从“链路是否可用”收敛到答案生成：短输出
限制、上下文选择、引用协议和关键事实保真均需改进；检索仍有 16.51% 的 Top5
缺口。

下一轮应先由数据所有者审核权限、有效版本、冲突和低置信样本，将确认项提升
为 gold；再在同一数据修订上做 no-rerank / `auto` rerank 对照和至少三次重复
测量。发布门禁应分别约束 Recall@5、引用正确率、答案忠实度和权限负样本，
不能用单一平均分替代。Grounding verifier 开启前，本报告不声称答案忠实性已
通过验证。
